# Particle Microstructure Generator

Version 1.0, September 1, 2026

## What It Does

Particle Microstructure Generator converts particle-size distributions and mixture proportions into randomized, non-overlapping 3D spherical-particle structures. It supports rigid and periodic boundaries, several placement methods, visualization, slice export, and grouped MCD, CN, ND, and MP calculations.

## System Requirements

- 64-bit Windows 10 (version 21H2 or later) or Windows 11
- 8 GB RAM minimum; 16 GB or more recommended
- Several GB of free storage for MATLAB Runtime R2024a and generated files
- Internet access during installation unless MATLAB Runtime R2024a is already installed

MATLAB is not required. The installer downloads MATLAB Runtime R2024a when needed. Large particle systems can require substantially more memory, storage, and processing time.

## Installation

1. Download and run `ParticleMicrostructureGeneratorInstaller.exe`.
2. Choose an installation folder and allow MATLAB Runtime to download when prompted.
3. Launch **Particle Microstructure Generator** from the installed shortcut.

Use **Help** in the application to open the illustrated User Manual.
